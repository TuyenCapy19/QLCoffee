# QLCoffee
- Tên dự án: Hệ Thống Quản Lý Coffee
  
- Danh sách thành viên
  + Lê Thanh Tuyền
  + Đặng Trường Huy
    
- Bảng phân công nhiệm vụ - Task list (kèm người phụ trách)
  
  + Lê Thanh Tuyền - thiết kế trang và chức năng trang
    inventory.php: Quản lý kho nguyên liệu
    reports.php: Thống kê doanh thu
    staff.php: Quản lý nhân viên
    database.sql: Cấu trúc CSDL
    index.php: Trang chủ tổng quan
    
  + Đặng Trường Huy - thiết kế trang và chức năng trang
    menu.php: Quản lý menu món coffee
    orders.php: Hệ thống order
    login.php & logout.php: Đăng nhập/đăng xuất
    database.php: Kết nối CSDL
